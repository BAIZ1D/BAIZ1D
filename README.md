I am a Software Engineer and Researcher specializing in Information Retrieval, Natural Language Processing (NLP), and minimalist terminal utilities. I design and build software that bridges the gap between complex data systems and intuitive interfaces.

## Featured Projects

### [yterm](https://github.com/BAIZ1D/yterm)
A minimalist, privacy-focused terminal-based YouTube client. It provides fast search capabilities, custom playlists, and video playback without ads or trackers.
- **Stack**: Bash, FZF, MPV, yt-dlp

### [petition-legislation-matching](https://github.com/BAIZ1D/petition-legislation-matching)
A hybrid retrieval framework that evaluates cross-domain matching between citizen lay queries and structural statutory law, automating legal statute matching in online petition systems.
- **Stack**: Python, PyTorch, Transformers, Qdrant (Vector DB), BM25, spaCy (Blackstone)
